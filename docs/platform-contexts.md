# Контексти платформи

Users володіє користувачами та заявками, Companies — компаніями, Notifications — сповіщеннями й шаблонами.
HTTP-контракти Aggregator визначені локально; посилань на DLL мікросервісів немає.
Gateway зберігає маршрути, але не бізнес-дані.

[ERD і правила дублювання попередніх лабораторних](../database/lab01/README.md).
[Документи MongoDB, ObjectId та приклади запитів](../database/lab04/README.md).

Огляд користувача читає одну сторінку заявок і одну сторінку сповіщень паралельно,
потім паралельно завантажує компанії з цієї сторінки заявок.
Порожній список заявок означає відсутність заявок на сторінці, а не перевірку існування користувача.
Під час збою Users компанії також недоступні, бо їхні ID беруться із заявок;
сповіщення при цьому можуть бути повернуті.
