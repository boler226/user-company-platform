# Бази даних

Скрипти попередніх лабораторних не дублюються й не переносяться.

- Проєкт 1: `../database/lab01/users/` — PostgreSQL, Dapper та ADO.NET.
- Проєкт 2: `../CompanyService.Infrastructure/Migrations/Lab03/` і `DbContext/DbInitializer.cs` — EF Core.
- Проєкт 3: `../NotificationService.Infrastructure/Persistence/notification-schemas.json` та `Seeding/` — MongoDB.
- `../DatabaseSetup/` створює SQL-бази, логіни та MongoDB-логін перед запуском API.

Platform.AppHost використовує окремі постійні volumes platform-lab05-postgres і platform-lab05-mongo.
