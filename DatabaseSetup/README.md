# Підготовка баз даних

Цей консольний C#-проєкт готує бази перед запуском сервісів. Він не є API
і не повинен постійно працювати у фоні. Після завершення програма закривається.
У Docker його запускає сервіс `database-setup`.

## Файли проєкту

| Файл | Що робить |
|---|---|
| `Program.cs` | Читає налаштування й послідовно запускає підготовку SQL та MongoDB |
| `PostgresDatabaseSetup.cs` | Створює дві БД і логіни, виконує SQL-файли, видає права сервісам |
| `MongoDatabaseSetup.cs` | Налаштовує колекції, додає початкові документи, індекси й логін |
| `DatabaseSetup.csproj` | Підключає драйвери й копіює SQL/JSON із `database/lab01` у результат збірки |

## Чому SQL лежить окремо

У `database/lab01` зберігається **опис даних**, а тут — **код їх розгортання**.
SQL-файли можна відкрити в редакторі БД, показати на захисті або виконати вручну.
Не потрібно переносити визначення всіх таблиць у великі C#-рядки.

Порядок підготовки PostgreSQL: схема → процедури → початкові записи → поля
реєстрації → права доступу. Файли `04-verify.sql` не виконуються автоматично.
Для MongoDB порядок: валідація колекцій → початкові документи → індекси → логін.

Назви баз і порядок запуску залишаються сталими. Повторний запуск не видаляє
наявні дані; початкові записи додаються лише за їх відсутності.

Команди й параметри підключення наведено в [головній інструкції](../README.md).
